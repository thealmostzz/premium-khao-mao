# Facebook Social Placeholder Design

## เป้าหมาย

เตรียมช่องทาง Facebook ในส่วน Social Media โดยยังไม่ผูกกับเพจจริง เพื่อให้เพิ่ม URL ภายหลังได้โดยไม่ต้องปรับโครงสร้างหน้าจอ

## ขอบเขต

- เพิ่มแท็บ Facebook ถัดจาก Instagram และ TikTok พร้อมไอคอน Facebook
- เพิ่มฟีด Facebook แบบ placeholder ที่แสดงเมื่อเลือกแท็บ โดยใช้รูปสินค้าที่มีอยู่และไม่มีลิงก์ออกภายนอก
- เพิ่มปุ่ม CTA `ติดตาม Facebook` ใต้ฟีด
- ใช้ `href="#"` และป้องกันการนำทางจนกว่าจะมี URL เพจจริง
- ขยายตัวสลับแท็บให้รองรับทั้งสามแพลตฟอร์ม และบันทึกเหตุการณ์เลือกแท็บตามรูปแบบเดิม

## UX และการแสดงผล

แท็บ Facebook ใช้สไตล์ inactive เดียวกับ TikTok และเปลี่ยนเป็น active แบบสีเขียวเมื่อถูกเลือก ส่วน CTA ใช้รูปแบบปุ่ม outline เดียวกับ Instagram เพื่อไม่ให้แย่งความสำคัญจาก CTA สั่งซื้อหลัก หน้าเดสก์ท็อปและมือถือจะใช้ flex wrap เพื่อไม่ให้เกิด horizontal scroll

## ความปลอดภัยและการทดสอบ

ยังไม่มี external URL จึงไม่เปิดแท็บใหม่หรือส่งข้อมูลภายนอก ตรวจว่าแท็บทั้งสามสลับฟีดได้ถูกต้อง, CTA ไม่เปลี่ยนหน้า, และความกว้างมือถือไม่ล้นหน้าจอ
