# ซ่อน Corporate ชั่วคราว

## เป้าหมาย

ซ่อนความสามารถ Corporate/B2B ที่ยังไม่พร้อมใช้งาน โดยไม่ลบโค้ด เนื้อหา ข้อมูลแปลภาษา หรือสินทรัพย์เดิม

## ทางเลือก

1. ซ่อนเฉพาะเซกชันหลัก — ยังมีลิงก์ที่พาไปยังปลายทางที่มองไม่เห็น จึงไม่เลือก
2. ซ่อนเซกชันหลักพร้อมจุดนำทางทั้งหมด — ไม่มีทางเข้าถึงจากหน้าเว็บ และเปิดคืนได้ง่าย จึงเลือก
3. ลบโค้ดทั้งหมด — ขัดกับข้อกำหนด จึงไม่เลือก

## การออกแบบที่เลือก

- คง `<section id="corporate">` ไว้ แต่เพิ่ม `hidden` พร้อมคอมเมนต์ระบุว่าเป็นการปิดชั่วคราว
- คงปุ่ม Corporate ในส่วน Gift Set ไว้ แต่เพิ่ม `hidden` พร้อมคอมเมนต์เดียวกัน
- คงลิงก์ Corporate ใน footer ไว้ แต่เพิ่ม `hidden` พร้อมคอมเมนต์เดียวกัน
- ไม่แก้ไขข้อมูลสินค้า คำแปล รูปภาพ หรือ analytics event เพื่อให้เปิดใช้ภายหลังได้ครบถ้วน

## การทดสอบ

- ตรวจว่าไม่มีองค์ประกอบ Corporate ที่มองเห็นได้ใน DOM ที่เรนเดอร์
- ตรวจว่าลิงก์ `#corporate` ที่ผู้ใช้เข้าถึงได้ไม่เหลืออยู่
- รันชุดทดสอบของโปรเจกต์ที่เกี่ยวข้อง
